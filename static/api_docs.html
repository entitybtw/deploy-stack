deploy-stack API v1

REST API for managing sites and runners.

Authentication

Login: POST /api/v1/login with {"username":"...","password":"..."}. Get token, use as Authorization: Bearer TOKEN or cookie deploy_token=TOKEN.

Sites

GET/api/v1/sites

List all deployed sites

POST/api/v1/sites

Deploy site. Body: {"name":"x","dir":"/var/www/x","port":8080,"type":"php"}

GET/api/v1/sites/:name

Site info

DELETE/api/v1/sites/:name/remove

Remove site

POST/api/v1/sites/:name/restart

Restart container

GET/api/v1/sites/:name/logs

Container logs

Runners

GET/api/v1/runners

List runners

POST/api/v1/runners

Register runner. Body: {"name":"x","host":"1.2.3.4"}

Webhooks

POST/api/v1/webhook/forgejo
POST/api/v1/webhook/gitea
POST/api/v1/webhook/github
POST/api/v1/webhook/gitlab

Auto-deploy on push to main/master.

System

GET/api/v1/status
GET/api/v1/events

SSE event stream for real-time updates.
